## 简介

这是一个为Minecraft离线服务器设计的完整的账号系统，采用**RESTful API**架构风格开发

## 功能

包括但不限于登陆注册，完整的账号管理，可以根据本系统自定义对应客户端如：网页、登录服务器、服务器插件、社交软件机器人等，也可以使用较为简陋的默认配套客户端

## 使用方法

下载jar包，放置到一个新的文件夹中，在当前文件夹中打开命令行使用`java -jar ALogin.jar`
运行，首次运行会生成必要的配置文件和资源文件并自动关闭程序，配置完后再次启动即可

数据库的配置：首先需要先准备好一个空数据库，然后在配置文件中配置连接信息（可根据需要选择是否开启数据库连接信息脱敏），然后启动后会自动生成表结构

## 开发工具

- [**Java 21**](https://www.oracle.com/cn/java/) - 作为主要开发语言
- [**Solon**](https://solon.noear.org/) - 用于构建 RESTful API 服务

- [**JUnit 5**](https://junit.org/) - 单元测试框架
- [**ApiFox**](https://apifox.com/) - API 测试工具
